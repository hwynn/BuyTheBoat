==========================================
---Funds, a core concept to understand----
==========================================

First understand the idea of "funds" this program uses. It's the main feature of this program. 
You might have $2500 in your account, but if $1000 is going towards rent, $800 is going towards bills, 
you need $200 to replace the wind shield, and $50 is going towards a trip you want to take, you only have $450 free to actually spend. 
This program virtually separates those out into "fund jars", like jars of cash that's been set aside for a specific expense. 

           
   Total cash in your account. Unclear how much is safe to spend.
                  |
  ________________\______________________________
|                        $2500                     |


          Funds allocated in "fund jars"     "Free funds" left over
                     |                         |
  ___________________\__________________  _____/___
|       $1000     |   $800    | $200 |$50|  $450   |



While manually moving funds around yourself is possible, it will be most common to create a savings plan for an expense that automatically allocates money into a fund jar at a pace you determine.
After you enter any kind of expense (whether that's a regular bill or perhaps a boat you want to buy in a year), you have the option to "save and plan". 
This will let you fine tune the pace you want to set funds aside for that specific expense. On any given day, this program will have tracked 
all the money that's been set aside. The rest of the money for that day is called "free funds", and it's how much you're free to spend on whatever else.


=====================================================
----How do I use the program once it's launched?-----
=====================================================

+++ The first time you use the program +++

 1. First add your bank accounts. You'll need their name and current balance. Unfortunately credit cards aren't considered an "account" by 
    this program. Consider them either an expense or just add the expenses that come out of them into whatever account you pay the credit card with.

 2. These next steps can be done in any order:
     - You'll first want to add your whatever regular income you have and your bills.
        + Note: you can make a draft of your bills in the "spreadsheet" tab while you collect the information for them. Then finalize them 
                one row at a time when you're ready.
     - You should also add any one-time expenses you anticipate coming up that you'll want to plan around.

 3. Create savings plans for the expenses. This is done automatically for each bill. You can fine tune these savings plans any time for an expense. 
    You can even make one time adjustments to move funds around manually.

 4. Go to the "forecast" tab and click the forecast button. It will create a little calendar overview that shows when money moves around and 
    how much you're free to spend. Click on a day in the calendar to learn more.

+++ Any subsequent time using the program +++

 1. Manually update the bank accounts with how much you actually have in them. Yes, it's kind of annoying like that.

 2. Use the forecast tab to see how things are doing.

 3. Update stuff if you want.


====================================
------Updating the program----------
====================================

I won't pester you to update the program. But ff you see there's an update available on the github page for this project and you want 
to install it, you'll first have to export your current data. It will make a database file. Hold onto this somewhere. 

You can delete the entire folder for the old version of the program at this point. It won't hurt anything to keep it other than taking up space. 

Download the new version of the program from the Releases page (or build it again yourself). 
Launch the new version, and from there, import that database file that was created earlier. You now have the latest version of the program.
