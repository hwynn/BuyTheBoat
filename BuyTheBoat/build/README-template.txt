  This is budgeting program meant to help keep track of how much of your money is reserved for which expenses.

{HOW_TO_RUN}

What are all these folders?:
  This copy of the program is self contained inside this folder.
  You can rename the outer folder all you want, just don't mess with the inner ones.
  Everything this copy creates stays inside this one folder:
    data{SLASH}      this contains your database. It's created the first time you run the program.
    backups{SLASH}   this is a copy automatically created before you try using "Import Data"
    exports{SLASH}   this is where "Export Data" and "Export as Spreadsheet" get saved
    logs{SLASH}      error logs. I might ask you to send me stuff from here if you have problems.

Where should I put this?
{WHERE_TO_PUT}
  Just put it somewhere convenient.
